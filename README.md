# Dash+ — HTML5 раннер с редактором уровней

Запустить очень просто: откройте файл `index.html` в современном браузере (Chrome/Edge/Firefox). Никаких установок не требуется.

## Управление

- Space / ЛКМ: прыжок
- Shift: рывок вперёд (даёт короткую неуязвимость)
- P: пауза
- R: сброс уровня
- C: поставить чекпоинт (в режиме практики)
- V: убрать чекпоинт (в режиме практики)
- 1/2/3/4: выбрать скорость
- E: включить/выключить редактор уровней
- Enter: старт

## Редактор уровней

- Включите чекбокс «Редактор» вверху.
- Выберите инструмент: блок, шип или ластик.
- Слайдер «Дистанция размещения» задаёт, на каком расстоянии от игрока ставить объект.
- Клик по канвасу добавляет элемент выбранного типа на землю. В режиме ластика клик — удаление ближайшего.
- Кнопки «Сохранить/Загрузить» работают с `localStorage`. «Экспорт» выводит JSON в поле ниже.

Формат одного объекта уровня:

```json
{ "x": 1200, "y": 460, "width": 40, "height": 40, "kind": "block" }
```

## Кастомизация

- В панели сверху можно менять цвет игрока, фона и препятствий.
- Включить/выключить звук — флажком «Звук».

## Известные ограничения

- Столкновения со «шипами» аппроксимированы прямоугольником (визуально рисуются треугольники).
- Нет загрузки пользовательских треков и онлайна. Это простой оффлайн-проект.
